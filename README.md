# ODMatrix Viewer

[English](./README.en.md)

ODMatrix Viewer 是一个基于 Vite 的纯前端 OD 矩阵可视化工具，用来把 CSV 中的出发地 / 到达地流动数据聚合成网格热力图，并叠加在自定义底图上查看。

它适合用来做城市交通、模拟结果、物流流向或行为轨迹的快速浏览。当前实现完全运行在浏览器端，不依赖后端服务。

## 功能概览

- 导入 CSV 数据集并在 Web Worker 中分批解析，避免主线程卡顿。
- 导入 PNG / JPG 底图，与热力图叠加显示。
- 支持按小时查看单个时间切片，或切换为 24 小时全天聚合视图。
- 支持分别显示 O 点、D 点，或同时显示。
- 支持按出行原因分类筛选，并根据主导类别着色。
- 支持缩放、拖拽、悬停查看网格位置。
- 支持双击锁定单个聚焦网格。
- 支持按住 Shift 拖拽框选区域，对与该区域相关的流动进行反向聚合分析。
- 支持调整地图范围倍率与网格分辨率。
- 支持在设置页中编辑出行原因映射规则，配置保存到浏览器 LocalStorage。

## 技术栈

## 使用方式

### 主页面

1. 打开应用后，先点击 `Load CSV Dataset` 导入 OD 数据。
2. 如果需要空间参照，再点击 `Import Base Map (PNG/JPG)` 导入底图。
3. 在左侧控制栏调整：
   - `Base Map Opacity`：底图透明度
   - `Heatmap Opacity`：热力图透明度
   - `Map Size (Tiles)`：地图分析范围
   - `Grid Resolution`：网格粒度，单位显示为 `u`，换算约为 `1u = 8m`
   - `Time Slice`：小时切片
   - `Show All Day (24h)`：全天聚合
4. 在右侧控制栏切换：
   - `Origin (O)` / `Destination (D)`
   - 各个出行原因分类

### 视图交互

- 鼠标滚轮：缩放视图
- 左键拖拽：平移视图
- 双击网格：锁定单个聚焦网格
- `Esc`：清除单格聚焦或区域聚焦
- `Shift + 左键拖拽`：框选聚焦区域

### 高级配置页

打开 `settings.html` 或通过主页面右上角入口进入高级配置页，可以编辑出行原因映射 JSON。

配置特点：

- 默认配置来自 `src/config/reasons.json`
- 用户修改后保存到浏览器 `LocalStorage`
- 配置修改只影响当前浏览器环境
- 点击恢复默认会清空本地配置并回退到项目内置映射

## 数据格式要求

当前解析器按固定列位读取 CSV，且默认跳过第一行表头。

### 最低要求

- 文件必须是标准文本 CSV
- 第一行会被视为表头并跳过
- 每行至少要有 9 列
- 数据中不能依赖复杂 CSV 特性，例如带逗号的引号字段；当前实现采用简单的 `split(',')`

### 已使用的列索引

解析器当前读取以下列位：

| 列索引 | 含义 |
| --- | --- |
| 1 | 时间值，预期为 `0.0 ~ 1.0`，会映射到 `0 ~ 23` 小时 |
| 3 | 出行原因原始值，用于匹配原因分类 |
| 5 | Origin X |
| 6 | Origin Y / Z |
| 7 | Destination X |
| 8 | Destination Y / Z |

其余列会被忽略。

### 时间映射规则

解析器会按以下逻辑换算时间：

```text
hour = floor(timeValue * 24) % 24
```

### 出行原因映射规则

- 原始值会先转成小写字符串。
- 之后按当前原因配置中的 `keywords` 顺序逐项匹配。
- 既支持精确匹配数字 / 文本，也支持文本包含匹配。
- 如果没有命中，会落到最后一个分类作为兜底分类。

## 渲染与聚合逻辑

- 数据被聚合到规则网格中。
- O / D 点可以分别计数。
- 当启用单格聚焦时，显示“流向该格”或“从该格出发”的关联分布。
- 当启用区域聚焦时，显示与所选区域相关联的整体分布。
- 单元格颜色取决于主导原因分类。
- 单元格透明度取决于该格总量，并基于当前结果的 95% 分位数做强度归一化。

## 默认分类配置

默认分类配置位于 `src/config/reasons.json`，当前内置的分类包括：

- 工作与教育
- 家庭与居民
- 商业与休闲
- 工业与物流
- 公共服务与应急
- 公共交通
- 其余默认类别（如果配置中继续定义）

实际界面显示的分类数量以当前 JSON 配置为准。

## 已知约束

- 当前仅支持浏览器端本地文件导入，没有后端存储与协作能力。
- CSV 解析器是轻量实现，不支持复杂转义 CSV。
- 底图只支持手动导入图片，不包含地理配准流程。
- 空间坐标采用项目内部世界坐标和固定网格换算，不是 GIS 经纬度系统。
- 出行原因配置保存在浏览器本地，不会自动同步到代码仓库。
